# Cuentas que sigo · Administración

Acceso directo: [abrir la sección](https://soller-ara.github.io/soller-ara/admin/#cuentas-que-sigo). Empieza vacía. Se añaden perfiles de Instagram o páginas de Facebook por decisión editorial; no se importa ninguna fuente. No hay filtro territorial, de palabras o de categoría. «Preparar en Enlaces de redes» solo rellena la fuente y el enlace de un nuevo borrador, con Facebook e Instagram desmarcados. Si hay una edición en curso la conserva; para sustituir un borrador pide confirmación. El botón «Abrir publicación original» lleva directamente al post.

## Activar el archivo común y la lectura (una sola vez)

1. En el panel de Cloudflare, **Storage & databases → D1 SQL Database → Create database**. Crear una base vacía y privada, por ejemplo **soller-ara-seguiment**. En el Worker existente **soller-ara-admin → Bindings → Add a binding → D1 database**, elegirla y darle el nombre exacto **SOCIAL_WATCH_DB**. No hace falta crear tablas a mano.
2. En **Settings → Variables and Secrets**, añadir **WATCH_META_READ_TOKEN** como *Secret* con un token de lectura autorizado por Meta. Para Instagram, añadir también **WATCH_INSTAGRAM_ID**, el ID numérico de la cuenta profesional propia vinculada al token. No sustituir los secretos del sistema de publicación ni enviar tokens por chat. El archivo funciona aunque falten permisos: conserva la lista, identifica qué cuenta no se ha podido leer y permite abrir su perfil.
3. Actualizar el Worker con el [archivo completo](../worker/admin-worker.js). En el editor inglés: **Edit code → Deploy**. Si se usa Wrangler en lugar del panel, añadir primero el ID real de la base al bloque D1 indicado en [wrangler.toml](../worker/wrangler.toml), conservando los bindings existentes.
4. En **Settings → Trigger Events → Cron Triggers**, **conservar** `*/15 * * * *` y **añadir** `7,22,37,52 * * * *`. Este segundo horario solo consulta las cuentas de esta lista. No llama al recopilador ni a los endpoints de publicación.
5. Abrir [salud del Worker](https://soller-ara-admin.infosollerara.workers.dev/health): la versión **0.74** incluye la capacidad **social_watch**. Esto confirma la versión, no el permiso de lectura. Al entrar en **Cuentas que sigo**, debe verse «Lista privada de Administración». Añadir una cuenta elegida y usar **Comprobar lectura**: las respuestas de Meta se muestran por cuenta. Sin el binding o con el Worker anterior se ofrece una lista explícitamente **solo en este dispositivo**. Cuando el servidor esté conectado se pueden importar esas cuentas sin duplicarlas; el borrado de datos del navegador elimina una lista provisional.

## Qué cubre la lista

- Hoy, el día elegido o la semana de lunes a domingo, con las fechas originales en Europe/Madrid. Cambiar de día solo consulta el archivo. No se confunde la fecha de recogida con la de publicación.
- En la primera lectura se intenta recuperar hasta 30 días anteriores. Después conserva lo archivado y repasa un margen de dos días para recoger entregas tardías. Si se interrumpe la lectura, conserva lo ya guardado. Una cuenta que se quite pierde su historial en esta sección.
- La descripción identifica el tema y, cuando consta, la hora mencionada en el texto que ofrece Meta, sin descargar fotos ni guardar pies de foto completos. En publicaciones sin texto se indica esta circunstancia.
- Los perfiles personales, grupos, historias y contenido privado no se garantizan. Solo se usan las API oficiales de [Instagram Business Discovery](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/business_discovery/) y [páginas de Facebook](https://developers.facebook.com/docs/features-reference/page-public-content-access/), nunca una sesión personal. Si no se resuelve una URL de página de Facebook, usar la dirección pública que contiene su ID numérico. El permiso para publicar en cuentas propias es independiente.
- Se procesan hasta tres cuentas por turno, por orden de próxima revisión; la paginación se reanuda en turnos posteriores. La frecuencia por cuenta depende del número de cuentas, el volumen y la disponibilidad de Meta. No se informa de «cero publicaciones» cuando la lectura ha sido parcial o imposible.
